# My Learning Journal

Welcome to **My Learning Journal**, a personal blog website where I document my journey as a frontend developer. This project showcases my skills in HTML and CSS, with a focus on responsive design and accessibility.

## Features

- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop devices.
- **Blog Posts Grid**: Displays recent posts with images, dates, and summaries.
- **About Me Page**: Learn more about me and my journey as a developer.
- **Article Page**: Detailed blog posts with structured content and images.
- **Custom Styling**: Utilizes Google Fonts and custom CSS for a modern and clean look.

## Technologies Used

- **HTML5**: For structuring the website.
- **CSS3**: For styling and responsiveness.
- **Google Fonts**: For typography.
- **Responsive Images**: Optimized for different screen sizes.
